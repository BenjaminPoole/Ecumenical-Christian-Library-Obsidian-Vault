# Welcome to my Christian Library


<img src="https://scx2.b-cdn.net/gfx/news/2021/publication-of-500-yea-1.jpg" width=400 height=264>

Roughly 18k notes of Christian primary texts in English - from the classical world the New Testament was written into, through the Fathers, Councils, and Scholastics, to the Reformers, Puritans, and Evangelical writers. This vault is aimed as an ecumenical equivalent of New Advent, including both Catholic and Protestant works.

This is the web version of the open source [Obsidian Vault](https://github.com/BenjaminPoole/Ecumenical-Christian-Library-Obsidian-Vault)

All text is public domain and scraped agentically using Claude code. Wishing to reflect God’s grace, all resources are free without any obligation. Created by the computer scientist and armchair theologian Benjamin Poole 


# QuickStart 🚀

The best way to find resources is to search using the search bar or `Ctrl+k` e.g. try searching for [[The Westminster Shorter Catechism]]

Each folder or author has a helpful index in the folder root. Have a look at the [[Church Councils]] and [[Puritans]] indexes.

As an evangelical Anglican and computer scientist, I was really annoyed that the only good historical websites for studying historical sources was the Catholic New Advent. Which is excellent, but Protestants need an equivalent that includes our confessions and writings. CCEL has poor usability and Logos is behind a paywall.

With this in mind, I built a lightweight, text-based site optimised for reading like a book. No waiting for PDF downloads, you can just click or search with `Ctrl+k`, loading instantly. Most of what reaches your browser is the text itself, no bloated JavaScript.

The site is generated from my Obsidian vault with Quartz 5, plus pre- and post-build steps to optimise performance. Because everything is generated from my [collection of Markdown files](https://github.com/BenjaminPoole/Ecumenical-Christian-Library-Obsidian-Vault), it is easy to maintain.
